Chuka University Voting System 🗳️
A robust, Java-based electronic voting system designed to streamline university elections. This system provides a secure and seamless experience for administrators, candidates, and student voters through dedicated, intuitive dashboards.

🌟 Key Features
🔐 Admin Dashboard
Election Management: Create, schedule, and oversee multiple election categories.

Candidate Vetting: Review and approve candidate applications.

Voter Oversight: Manage the student voter registry and monitor real-time participation.

Results Analytics: Automated, tamper-proof tallying with graphical result summaries.

👤 User (Voter) Dashboard
Easy Registration: Secure login using university credentials.

Candidate Profiles: View detailed manifestos and photos of candidates before casting a vote.

One-Vote Policy: Integrated logic to ensure each student can only vote once per category.

Privacy: Anonymous ballot casting to ensure voter confidentiality.

🎖️ Candidate Dashboard
Application Tracking: Submit and monitor the status of your candidacy.

Profile Customization: Upload manifestos and campaign details directly to the voter interface.

🚀 Getting Started
Prerequisites
Java Development Kit (JDK): Version 17 or higher.

Database: MySQL (recommended) or any compatible SQL database.

IDE: IntelliJ IDEA, Eclipse, or NetBeans.
